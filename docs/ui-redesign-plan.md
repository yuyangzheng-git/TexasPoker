# TexasPoker UI 全面优化方案

状态：设计与实施方案，尚未替换现有界面。基于实际登录页及现有前端代码检查。

## 目标与方向

推荐采用「现代扑克俱乐部」：深墨绿背景、低饱和绿色牌桌、少量暖金强调、清晰的浅色扑克牌。游戏过程强调牌桌、手牌和下注决策，复盘强调信息阅读，管理后台强调数据操作。

不继续混用高饱和蓝、青、紫、黄，也不依赖大量霓虹光、表情图标和全大写等宽文字营造游戏感。

备选方向：竞技科技风适合后续 AI 研究展示；浅色训练工具风适合长时间分析。当前优先采用现代扑克俱乐部，复盘与后台保留更简洁的信息界面。

## 当前问题与优先修复

1. 登录页是通用深色表单，缺少扑克主题和产品识别。
2. 登录、游戏、大厅与后台没有统一的按钮、字体、颜色和间距体系。
3. 牌桌玩家以左侧列表展示，中央桌面视觉占比不足，桌上空间关系不直观。
4. 左侧玩家列表、固定 320px 右栏、固定 520px 操作面板争抢可用宽度。
5. 大量 10px 辅助文字、全大写文字及小按钮使对局信息难读。
6. 全局禁止滚动，容易截断注册页、个人页和后台长内容。
7. 小于 900px 的竖屏布局直接隐藏应用，内嵌浏览器窄面板也会被误判。
8. 全屏与横屏提示作用于整个产品，干扰登录和注册。
9. 游客入口与大厅的登录限制不一致，需要统一产品行为。
10. 上轮机制调整遗漏了大厅两个直接创建牌局入口的凭证保存；先统一调用现有 gameApi，再调整开局界面。
11. 当前本地算法演示与真实 LLM 模式没有明确的界面区分。

## 视觉规范

| 项目 | 建议 |
| --- | --- |
| 背景 | #0B1412 |
| 普通内容表面 | #14211D |
| 浮层与输入区域 | #1B2C25 |
| 牌桌 | #174B3A，细微明暗变化 |
| 主强调 | #C8A86A，主要行动和当前选中状态 |
| 正文 | #F2F1E9 |
| 次要文字 | #A6B3AA |
| 弱分隔线 | #2A3D32 |
| 错误与危险 | #DC7777，小面积使用 |
| 字体 | 中文与英文使用统一无衬线字体；金额采用等宽数字，不让整页变成等宽字体 |
| 字号 | 正文 14–16px，重要信息 18–24px，辅助文字至少 12px |
| 间距 | 统一 4/8/12/16/24/32px 节奏 |
| 圆角 | 输入与按钮 10–12px，内容面板 16–20px |
| 图标 | 同一套线性图标；角色使用统一比例与风格的头像 |
| 状态 | 默认、悬停、聚焦、按下、禁用、处理中、成功和失败均有一致规则 |

暖金用于强调，不给整块内容加金边。成功、警告与错误同时使用文字或图标说明。最终配色按实际文字背景逐项检查可读性。

## 页面方案

### 登录与注册

桌面采用品牌介绍与表单的双栏布局，品牌侧用牌面与简洁牌桌构图传达主题；表单侧保留一个清晰的主要操作。手机采用单栏。

- 使用「与不同风格的 AI 对手对局，赛后查看决策复盘」等准确介绍。
- 当前演示模式明确标注「本地算法演示」，不暗示正在调用真实 LLM。
- 中文默认，支持统一切换英文，避免同一页面混杂两种语言。
- 输入框具备明确标签、自动填充、密码显示切换及就近错误提示。
- 登录与注册提交中只改变按钮状态，保留已输入内容；避免整页转圈。
- 游客体验若保留，真正允许进入本地演示大厅；否则移除失效入口。
- 不让横屏或全屏遮罩阻止用户完成账户流程。

### 大厅

建立「直接开始—配置对局—了解对手」三层结构。

- 首屏突出「快速开始」，默认设置可直接使用。
- 标准设置只保留人数、对手难度、初始筹码；未支持的设置不做成可操作选项。
- 人格筛选、对手指定与座位编排收进高级设置，默认收起。
- 显示清楚的创建结果预览，例如「6 人桌 · 你与 5 位对手 · 演示模式」。
- AI 列表统一头像、名称和一句风格介绍；完整人格描述放进详情。
- 配置区域可滚动，开始按钮在小屏保持可达，不能盖住选项。
- 正在创建、创建失败、服务不可用分别给出明确反馈与重试操作。
- 不展示虚构的在线人数、匹配人数或实时活动。

### 牌桌主界面

桌面主结构为「顶部状态—中央牌桌与环形座位—底部操作—可折叠侧栏」。玩家本人固定在下方易见位置；庄家与盲注位置同步真实游戏状态。

- 中央牌桌占据主要视野，公共牌与底池是视觉中心。
- 玩家围绕牌桌排列，不再以左侧长列表承担主要座位展示。
- 每个座位优先显示头像、名字、筹码、本街下注和最后一次行动；位置等辅助信息弱化。
- 当前行动者用简洁进度环或边缘提示强调，同时明确显示「轮到你」。
- 弃牌玩家弱化，全押使用文字标签，不能只靠颜色区分。
- 主池和边池按需要展开，默认保持清晰总览。
- 右侧栏包含行动记录、公开发言、赛后复盘，默认可折叠；对局中不展示私密思考。
- 顶部模式与连接状态简洁可见，减少重复显示的金额与调试式标签。

### 扑克牌与筹码

- 自己的手牌使用更大尺寸，数值和花色在桌面与手机上都可快速辨认。
- 牌面使用统一比例、明确角标和克制阴影；牌背使用同一品牌纹样。
- 可提供四色牌辅助辨认，但必须保留花色符号。
- 下注金额直接读数，筹码堆只作为辅助视觉，不要求玩家数筹码。
- 洗牌、发牌、翻牌和底池分配只保留帮助理解顺序的动效。

### 下注操作区

- 从遮挡牌桌中央的浮动大面板改为底部稳定操作区。
- 仅展示当前合法的过牌、跟注或加注；跟注按钮直接显示实际投入。
- 加注区同时提供金额输入、滑块和快捷比例，统一解释为「加注到 X」。
- 快捷额度经过合法范围校验；筹码不足时提供清楚的全押语义。
- 全押与普通操作拉开距离，减少误触。
- 提交后立即呈现等待确认状态，防止连续点击；非法操作保留用户输入并解释原因。
- 剩余时间清楚可读；最后几秒才适度强调，避免持续闪烁和重复声音。
- 自定义发言收进次要入口，不能挤占关键操作空间。

### 结算与复盘

- 不再用大面积遮罩、骷髅图标和夸张输赢标题盖住牌桌。
- 显示温和的本手结果摘要：净变化、获胜者、牌型、底池分配。
- 结算摘要可收起；用户仍能查看刚才的公共牌、自己的手牌和已公开对手牌。
- 提供「下一手」「查看复盘」「返回大厅」，整场结束时不再显示可继续的假入口。
- 多边池的分配明细可展开，默认每位玩家一条结果。
- 复盘按照翻牌前、翻牌、转牌、河牌组织，结合实际记录的行动与 AI 赛后思考。
- 没有记录的数据不伪装成评估结果，不虚构 GTO 分数、策略准确率或胜率曲线。

### 个人中心

使用统一的页面导航，把资料、实际可用的游戏统计和偏好设置分区。更改资料与密码只在对应区域反馈，不让整个页面重置。

优先支持声音、动画强度、语言及牌面偏好；统计只展示后端已可靠记录的数据，暂无数据时说明如何产生第一条记录。

### 管理后台

沿用同一字体与基础组件，使用更简洁的数据布局。

- 统一侧边导航、标题、工具栏、表格和详情抽屉。
- 用户、牌局、AI 配置和系统设置分别提供合适的搜索、筛选与分页。
- 危险操作与普通编辑明确区分，提交前显示将改变的对象和内容。
- 长表格与长设置页可以正常滚动，窄屏导航改为抽屉。
- 状态使用固定含义的标签，避免仪表盘每个指标都使用不同颜色。
- 缺少数据接口的图表先保留真实空状态，不填装饰性统计。

## 响应式与可访问性

- 桌面宽屏：完整环形牌桌，可展开侧栏。
- 中等宽度：侧栏变为抽屉，优先保证牌桌和操作空间。
- 手机竖屏：紧凑牌桌与座位布局、底部操作区、记录和复盘底部抽屉。
- 手机横屏：减少顶部高度，保持手牌和操作易读。
- 布局依据实际可用宽度调整，避免将内嵌浏览器误判为必须横屏的手机。
- 页面使用动态视口高度与安全区留白；表单弹出键盘后仍能滚动到提交按钮。
- 全屏和横屏只作为用户可选择的增强功能。
- 触摸目标至少约 44px；支持键盘、可见焦点、读屏标签与减少动态效果。
- 仅牌桌画布控制溢出；登录、个人页、后台等内容页允许正常纵向滚动。

## 系统状态与交互文案

| 状态 | 建议行为 |
| --- | --- |
| 首次进入 | 清晰的模式说明与开始入口 |
| 创建牌局 | 按钮内进度，防止重复创建 |
| AI 决策 | 指向实际行动者的状态提示；不输出私密思考 |
| 临时断线 | 保留牌桌，顶部显示重连状态，暂时禁用行动 |
| 凭证失效 | 解释原因并提供返回大厅入口，不无限转圈 |
| 其他窗口占用 | 告知牌局已在另一窗口打开 |
| 非法下注 | 在操作区解释合法额度，保留可重试状态 |
| 暂停 | 说明当前行动结束后生效及已有行动的时限 |
| 超时 | 明确显示服务器执行了过牌或弃牌 |
| 空记录 | 说明目前没有数据及下一步操作 |
| 服务错误 | 提供具体恢复路径，避免把内部异常直接展示给玩家 |

## 实施顺序

### 第一批：恢复完整体验，确定统一外观

修复大厅凭证衔接与游客入口；移除阻断访问的全局横屏限制；建立颜色、字体、间距、按钮、输入框和提示组件。完成登录、大厅、核心牌桌与下注区的桌面及手机布局。

### 第二批：完善对局中的信息与反馈

完成座位、牌面、筹码、当前行动提示、连接状态、提交状态、结算与赛后复盘。统一个人页和管理后台的页面结构。

### 第三批：完成精修与验收

补充轻量动效与声音偏好，完成键盘及读屏检查、不同尺寸截图对比，以及多人数、全押、边池、断线和长文本场景的回归验证。

## 验收标准

1. 新用户能够看懂当前模式，并完成从登录或游客体验到第一次合法行动的路径。
2. 320px、390px、768px、1024px 和 1440px 宽度下，关键内容不遮挡、不溢出、不依赖强制旋转。
3. 2 人、6 人和 9 人对局，当前行动者、自己的手牌、底池与可用操作始终清楚可见。
4. 长昵称、长发言、较大金额及复杂边池不会破坏布局。
5. 登录与注册失败、创建失败、断线重连、非法操作及整场结束均有明确反馈。
6. 结算后能继续查看牌桌与复盘，下一手与返回大厅都有正确行为。
7. 视觉组件和语言保持一致，真实 LLM 与本地算法演示模式不会混淆。
8. AI 思考与底牌的可见性遵循已有信息保护机制。
9. UI 调整后保留现有规则与连接测试，并补充关键页面流程及响应式验证。
