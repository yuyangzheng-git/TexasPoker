# LLM Agent Prompt 工程

## Prompt 结构

### 第1层：人格注入
```
你是德州扑克玩家【赌神】。

【性格设定】
大胆激进，永不服输。频繁大注施压对手。喜欢虚张声势。

【风险偏好】
激进 (temperature 0.9)
```

### 第2层：牌局状态
```
【当前牌局状态】
- 你的手牌: Ah Kd
- 你的筹码: $500
- 底池大小: $150
- 当前最高下注: $50
- 你需要跟注: $30
- 下注轮: flop
- 公共牌: Qs Js 8h
```

### 第3层：数学指标
```
【数学分析】
- 你的股似率: 62%
- 底池赔率: 20%
- 保本所需胜率: 20%
- 期望值评估: 正期望值 ✓
```

### 第4层：对手分析
```
【对手分析】
[Alice] 激进型 | VPIP 48% | 近期: raise → call → call
[Bob]   保守型 | VPIP 18% | 近期: check → fold → fold
```

### 第5层：历史记忆
```
【你的历史记录】
总手数: 127, 胜率: 54%, 累计盈亏: +$245
近期: W W L W L W
```

### 第6层：输出格式
```
【决策要求】
请严格按照以下格式回复:

<thinking>
(100-200字分析)
</thinking>

<action>
fold | call | raise 100 | allin | check
</action>

<speech>
(可选，1句对话)
</speech>
```

## Token 预算

| 部分 | Token |
|------|-------|
| 系统人格 | 200 |
| 牌局状态 | 150 |
| 数学分析 | 80 |
| 对手分析 | 200 |
| 记忆摘要 | 150 |
| 指令格式 | 100 |
| **总计** | **~880** |
| 输出 | 100-200 |

## 解析+降级策略

1. **成功**：解析 <thinking> <action> <speech>
2. **解析失败**：重试 1 次，再失败则用默认行动
3. **超时**：15秒后自动执行 fallback（基于 equity）
4. **规则违反**：自动修正为合法动作
